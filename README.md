# 🥗 NutriGuide

NutriGuide is a Flask-based nutrition and wellness web application designed to help users adopt healthier eating habits. It provides personalized diet plans, a calorie tracker, informative health blogs, and nutrition resources through a clean, responsive interface.

---

## 📖 About the Project

NutriGuide aims to make healthy living easier by offering users access to diet plans, calorie tracking, nutrition articles, and essential health information in one place.

This project was developed using **Python Flask** for the backend and **HTML, CSS, and Jinja Templates** for the frontend.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/msarayu17/NutriGuide.git
```

### 2. Navigate to the Project Folder

```bash
cd NutriGuide
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000/
```
